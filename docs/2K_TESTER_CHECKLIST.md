# 2K Assessment QA — External Tester Checklist

This checklist provides the formal validation steps for the LingoPure 2K assessment flow (ISS-038/ISS-042). All testers must complete these steps using a real device/user context.

## 1. Setup
- [ ] **Environment:** Use a real device (iPhone/Safari, Android/Chrome) or Desktop Chrome.
- [ ] **Auth:** Authenticated account using provided test credentials.

## 2. Execution Flow (G1–G14 Acceptance Gates)

### Assessment Journey (G1, G2, G3)
- [ ] **Capture:** Complete full 25Q assessment. Verify consistent mic capture/upload across all questions.
- [ ] **Resume:** Start an assessment, interrupt at Q13 (close tab), then resume from Q13. Verify prior responses are retained and no duplicate evidence was created.

### Results & Consistency (G4, G7, G8)
- [ ] **Authority:** Verify the 2K assessment result is generated by the backend pipeline.
- [ ] **Consistency:** Verify that the Learner View and Teacher View resolve to the same `result_id` and frozen state.

### Teaching & Closed Loop (G9, G10)
- [ ] **Outcome:** Teacher records outcome/intervention against the result.
- [ ] **Closed Loop:** Verify the outcome lands as new evidence without overwriting historical raw observations.

### Recovery & Operations (G11, G12)
- [ ] **Upload Failure:** Disable Wi-Fi during an upload; verify session resumes gracefully on reconnection.
- [ ] **Traceability:** Check the `/status` route for the current assessment and verify all event ledgers are visible and accurate.

### Security (G13)
- [ ] **Media Access:** Attempt to access an unauthorized audio URL for a response you don't own. Verify the denial is logged in the system.

## 3. Reporting
- Submit all findings to the issue tracker. Include the following for every failure:
  - `assessment_id`
  - Observed behavior vs. expected result
  - Device/Browser information
  - Relevant timestamps
